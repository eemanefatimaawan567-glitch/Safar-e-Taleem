SAFAR-E-TALEEM — Smart School Transport for Pakistan
====================================================
AI-powered platform that cuts school transport costs for Pakistani families
through walking-group clustering, fuel-aware hybrid scheduling, and
Roman-Urdu voice assistance. Built for the Alibaba Cloud Hackathon.

----------------------------------------------------
TOOL 1: AI WALKING GROUPS (Safe Walking School Bus)
----------------------------------------------------
How it works:
  Instead of paying for a van, parents register with their neighborhood
  and GPS location (e.g. "G-11, Islamabad").

The AI part:
  DBSCAN clustering (scikit-learn) instantly groups families who live
  within 0.5 km of each other and attend the same school. The engine is
  smart — if the school is close it builds a walking group; if it is far
  it switches to motorcycle or carpool sharing, so fuel costs are cut
  regardless of distance.

The result:
  A "Walking School Bus" where parents take turns walking the children
  to school together. Fuel cost = 0 PKR. Carpools cut costs by 50%.

----------------------------------------------------
TOOL 2: HYBRID SHIFT PREDICTOR (For Principals)
----------------------------------------------------
How it works:
  The principal has a live dashboard monitoring real fuel prices
  (petrol, diesel, kerosene, LPG) from the PSO/TrackMate feed.

The AI part:
  If petrol crosses the critical threshold (Rs 380/L), an OGRA-style
  red alert flashes: "Fuel Price Critical!" An interactive simulator
  lets principals test any price scenario in the browser.

The result:
  With one click, the system generates a hybrid timetable
  (e.g. 3 days physical / 2 days online), cutting transport costs by
  40% for every family. History is charted live with Chart.js.

----------------------------------------------------
TOOL 3: "ASK AMMI/ABBA" — Roman-Urdu Voice AI
----------------------------------------------------
How it works:
  Many struggling parents cannot read English or use complex apps.
  The app has one giant microphone button.

The AI part:
  A mother taps the mic and speaks naturally: "Petrol bohot mehenga
  hai, bache ko school kaise bheju?" Alibaba Qwen AI processes the
  voice command (Web Speech API STT) with full conversation memory.

The result:
  The AI speaks back a helpful, localized carpool or walking-group
  solution entirely in Roman-Urdu audio (TTS). No typing, no English.

----------------------------------------------------
TOOL 4: LIVE SAFETY TRACKING + SOS
----------------------------------------------------
Parents share their child's live GPS location (Leaflet.js map) with
pod-mates during the walk or carpool to school — updates push in real
time over server-sent events (no polling lag). One tap on SOS sends an
instant emergency alert to the whole group and the principal's
dashboard, with a live OpenStreetMap location link. Commutes end when
children arrive safely.

----------------------------------------------------
TOOL 5: MOHALLAH STUDY PODS
----------------------------------------------------
On hybrid/online days, families with a smartphone or laptop host up
to 3 nearby families without one — so kids share a single screen
safely within walking distance. Reuses the same proximity clustering
as the walking-group matcher.

----------------------------------------------------
TOOL 6: OFFLINE LEARNING PACKETS + WHATSAPP/SMS/IVR
----------------------------------------------------
No child misses online days: principals generate printable curriculum
PDFs (Primary/Middle/Secondary, federal board aligned) and broadcast
summaries via WhatsApp, SMS, or IVR voice calls to families without
devices — through the real Meta WhatsApp Cloud API and Pakistani HTTP
SMS gateways when configured, with a zero-setup simulation mode so the
demo always works — plus a full delivery log and an in-app alert feed.

----------------------------------------------------
ENGINEERING & DEPLOYMENT
----------------------------------------------------
- PWA: installable app with offline-first service worker (works on
  flaky 3G, caches the app shell, friendly offline banners)
- Tested: full pytest suite — clustering engine, Haversine distance,
  carpool economics, geo services, notification providers, AI fallbacks,
  petrol pricing, curriculum content, and 371 tests across unit, integration,
  and API layers
  (auth + CSRF, registration validation, SOS dispatch, pod coordination,
  SSE stream, rate limiting) against a throwaway seeded database
- One-click deploy: render.yaml blueprint + Procfile (gunicorn)
- Tech stack: Flask + SQLite + scikit-learn DBSCAN + Leaflet.js +
  Chart.js + Alibaba Qwen AI + Web Speech API + xhtml2pdf
- Design system: Deep Emerald (#004D40) + Safety Amber (#FF7A00),
  native system font stack (zero web-font downloads)
